## Logica Marketing (Next.js 15)

Многостраничный маркетинговый сайт: услуги (хаб + детальные), кейсы, о нас, контакты. Mobile-first, SEO-friendly, с анимациями Framer Motion.

### Как развернуть БЕЗ установок на компьютере

#### 1) Подготовьте лого для сайта

- Переместите ваш файл `logo.png` в папку `public/` и переименуйте в `public/logo.png`.
- Если папки `public` нет — создайте её.

#### 2) Залейте проект в GitHub через браузер

- Откройте GitHub → `New repository` → создайте репозиторий (например `logica-marketing`).
- В репозитории нажмите `Add file` → `Upload files`.
- Перетащите **все файлы и папки** из этой директории в окно загрузки.
- Нажмите `Commit changes`.

#### 3) Задеплойте на Vercel (сборка на их серверах)

- Откройте Vercel → `New Project`.
- Импортируйте созданный репозиторий GitHub.
- Framework: **Next.js** (определится автоматически).
- Нажмите `Deploy`.

#### 4) (Опционально) Укажите домен сайта

Чтобы корректно генерировались `sitemap.xml`, `robots.txt` и OpenGraph URL:

- В Vercel → Project → Settings → Environment Variables
- Добавьте переменную:
  - `NEXT_PUBLIC_SITE_URL` = `https://ваш-домен.ру`
- Redeploy.

### Следующий шаг (когда захотите)

- Подключить отправку формы на странице `Контакты` через Server Actions (в Telegram/Email).
- Добавить реальные кейсы и изображения.
- Подключить аналитику (GA4/Meta Pixel) и события.
